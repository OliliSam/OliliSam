## 🌐 Deploying & Running This Portfolio

### Option 1: Deploy Directly to GitHub Profile README
To display this portfolio directly on your GitHub profile:
1. Create a public repository named `OliliSam` on GitHub (`https://github.com/OliliSam/OliliSam`).
2. Copy the contents of this `PORTFOLIO.md` file and name it `README.md` in that repository.
3. Commit and push. GitHub will automatically render it as your official profile page!

### Option 2: Deploy to Vercel / Netlify / Cloudflare Pages
The companion interactive web portfolio is located in the `./portfolio` directory:
```bash
# Preview locally:
cd portfolio
node server.js
# Access at: http://127.0.0.1:4173
```
- For **Vercel**: Import the repository and set the root directory to `portfolio`.
- For **Netlify**: Set base directory to `portfolio` and publish directory to `.` (Static HTML/JS/CSS, no build step required).
- For **GitHub Pages**: Go to Repository Settings -> Pages -> Deploy from branch -> choose `/portfolio` or root.
